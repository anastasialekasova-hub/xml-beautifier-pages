# XML Beautifier — pages

Welcome, uninstall and feedback pages for the XML Beautifier Chrome extension, served via GitHub Pages.

- `welcome/` — opened once after installation
- `uninstall/` — opened by Chrome after the extension is removed (short survey)
- `feedback/` — opened from the in-extension rating prompt for 1–3 stars

Privacy policy: https://pinwisp.com/xml-beautifier/privacy/
